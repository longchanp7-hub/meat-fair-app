# 肉・食べ放題フェア

15チェーンの公式フェアを、1ブランド1カードでまとめる静的Webアプリです。

公開先: https://longchanp7-hub.github.io/meat-fair-app/

## 情報の扱い

- 公式の料理・フェア画像を使用。画像は切り抜かず全体を表示します。
- 開催中・近日開始・新着・終了間近を日本時間で判定します。
- 取得できないチェーンは「要確認」と表示し、「フェアなし」とは扱いません。
- 価格、対象コース、曜日、予約条件、対象店舗の制限を別々に保持します。
- 対象店舗を確認できない情報から、近隣店舗で利用できるとは推定しません。

## 更新・検証

`npm test` → `npm run quality-gate` → `npm run update` → `npm run verify`

GitHub Actionsが毎日09:00 JST頃および関連コード更新時に15チェーンを巡回します。実行開始はGitHub側の混雑により遅れる場合があります。公開前の回帰テストに加え、公開ファイルのハッシュ照合と390px／1180pxの実ブラウザ検証を行います。

取得失敗時は前回の確認時刻を維持したまま最大7日間の既知データを使用します。終了日を過ぎたフェアはこの間も表示しません。

## 公式サイト変更時

`scripts/reviewed-campaigns.json`には確認済みのフェア・画像・条件と、該当本文・画像のハッシュを記録しています。公式本文が変わった場合、古い確認内容を無条件で適用せず、候補として再確認します。未確認候補・取得エラーは`app/data/candidates.json`、公開用は`app/data/fairs.json`に分離しています。

新規の公式情報はブランド別の本文範囲・URL規則で抽出します。確かな開催期間と料理画像などの基準を満たすものだけを公開し、日付が不明なものを当年開催と推測しません。画像の表示権利は各提供元に帰属します。

アプリ本体に外部ランタイム依存はありません。ブラウザテスト用PlaywrightはGitHub Actionsの一時ディレクトリにのみ導入します。既存の寿司アプリとは別リポジトリ・別公開先です。
