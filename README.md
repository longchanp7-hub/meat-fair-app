# 食べ放題・肉フェア発見アプリ

既存の寿司フェアアプリを壊さず、別リポジトリ／別GitHub Pagesで動かす兄弟アプリです。

## 方針
- 公式情報をSource Registryから巡回
- 毎日09:00 JST前後にGitHub Actionsで更新
- candidate → normalize → deduplicate → quality gate → production
- ブランド単位のLast Known Good
- 取得失敗時は怪しい新データを公開せず前回正常データを維持
- 「開催中 / 新着 / 近日開始 / 終了間近」を表示
- 収集と通知は分離

## 実装段階
現在はPhase 1〜4の骨格です。最初に2〜4ブランドをend-to-endで通し、その後15ブランドへ展開します。
