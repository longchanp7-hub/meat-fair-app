# 2026-09-15 UI review — 肉匠坂井ベース

「ちょっと一緒に見ていこう」以降の実機レビューを反映した表示方針。

## 共通方針

- `チェーンで絞り込む` では件数を出さず、開催中の P1 フェアがあるブランドだけ `注目フェア` を表示する。
- 基本構成は **フェア → コース・料金 → 飲み放題 → 必要なランチ／お得情報**。
- コース料金は比較可能な同条件内で安い順。縦型スマホでは肉匠坂井のように上から自然に積む。
- 写真付きのコース／飲み放題パネルがある場合、同じ内容の文字だけパネルは重複表示しない。
- 写真がない情報は、必要な料金・条件だけを横長の小さな「座布団」型パネルに圧縮する。
- 通常料理の「注目メニュー」や個別料理写真は原則表示しない。フェアそのもの、コース比較、飲み放題、行く理由になる割引を優先する。
- 飲み放題は酒類の個別写真より、**有無・区分・税込価格**を優先する。
- 串家物語は近隣優先度が低いため対象から外し、14チェーン構成とする。

## ブランド別

- 焼肉きんぐ: フェア本体、58品／きんぐ／プレミアムの写真付きコース、ランチ小パネル、ソフトドリンク／アルコール込み飲み放題のみ。
- 牛角: フェア、主要コース、飲み放題に集約。注目メニューを出さない。
- しゃぶ葉: 鴨しゃぶ本体＋九州黒豚／黒毛和牛を上部で優先。個別の鴨肉・きのこだし等は出さず、ランチ／ディナー／主要コースを小さな料金パネルで表示。
- ゆず庵: ランチ／お手軽／ゆず庵／贅沢の写真付き通常コースを中心にし、サーモン等の個別メニューと重複テキストを出さない。飲み放題は維持。
- 和食さと: フェアは維持し、さとしゃぶ／さとすき／さと式焼肉を区別して料金表示。宴席・通常メニュー・さとカフェ／さとバルの大きな写真は使わず、飲料料金はコンパクト表示。
- あみやき亭: 厚切りフェスの大画像と、その下の有用な小写真は維持。コース写真も維持し、補助テキストは座布団型に圧縮。
- しゃぶしゃぶ温野菜: 個別料理・注目メニューを外し、フェア、コース料金、飲み放題に集約。
- 露菴: 現在のシンプルな情報密度を基準として維持。
- カルビ大将: 全メニュー画像を外し、コース料金と飲み放題の有無・価格に集約。
- すたみな太郎: 写真のない牛タン／中落ちカルビ等の注目メニューを外し、ランチ／ディナー／飲み放題のシンプル構成。
- ステーキのあさくま: 上部の主要フェア画像を残し、アボカド、カレー、スープ等の個別メニューを外す。下部はサラダバー情報を中心にする。
- 肉匠坂井: 基準レイアウト。フェア → 写真付きコースを安い順 → 写真付き飲み放題。重複テキストは出さない。
- 熟成焼肉いちばん: ライト／いちばん／牛タン／黒毛和牛など写真付きコースを揃ったサイズで表示し、重複テキストを削除。飲み放題／ドリンクバーも写真が有用なら残す。
- 安楽亭: 写真付きコース／飲み放題を優先し、下側の重複する文字だけパネルを削除。

PWA の manifest、専用 scope、Service Worker とネットワーク優先データ取得方針は変更しない。
