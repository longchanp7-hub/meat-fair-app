# 自動ギャラリーの仕上げ（2026-09-15）

共通自動配置・公式画像収集の既存実装を維持し、縦型スマホでの可読性を追加改善。

- 公式の補助画像でも、ファイル名が `*_title` / `*_text` / `*_sign` の見出し・文字片は表示対象から外す。フェアの審査済みメイン画像は除外しない。
- メイン画像が未設定の場合、同一の審査済みフェアID・内容ハッシュに結び付いた新しい補助画像から代表画像を選ぶ。古い／別フェア／別チェーンの画像は使わない。代表に使った画像を補助枠で重複表示しない。
- 画像の代替テキストに税込額が明記されている場合だけ、金額を独立した行に表示する。税計算や価格推測はしない。追加料金をコース料金として抜き出さない。原文は alt、title、アクセシブル名に保持する。
- 説明帯は価格なし64px相当、価格あり88px相当を基準とするrem指定。文字サイズ変更も監視し、説明帯の実測高さと文字倍率に応じてタイル幅／配置を再計算する。
- キャッシュ対策として変更したアプリ・ギャラリー・CSSの参照バージョンを更新。PWAの識別子・スコープ・インストール処理・Service Workerは変更しない。

`tests/gallery-polish.test.mjs` は価格抽出、文字片除外、代表画像の安全な選択、重複排除、HTMLエスケープ、15チェーン×9幅×4文字倍率（540通り）の幾何配置を検証する。
`tests/browser-public.cjs` は既存の6幅・全チェーン・全タブ検証に加え、価格の省略／縦方向の文字切れと125%／150%／200%文字サイズ変更後の再配置を検証する。

これは無条件に空白を塗りつぶす処理ではない。元画像内の余白や価格・文字は切らず、明確な公式画像がない場合は無関係な画像で埋めない。
